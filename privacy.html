Privacy Policy

Last updated: 17 November 2026

Who uses this app

Dark Atlas Uploader is a private tool used only by the owner of the YouTube channel Dark Atlas to manage that channel's own videos. It is not offered to the public.

What data is accessed

With the channel owner's consent (Google OAuth), the app uses the YouTube Data API to:

  • upload the channel's own video files and thumbnails,
  • set title, description, tags, category, language and publication time of those videos,
  • read basic information and statistics of the owner's own channel and videos.

The app does not access other users' data, comments, subscribers' personal data, e-mail or contacts.

Storage

The OAuth access token is stored only locally on the channel owner's own computer. No data is sent to any server other than Google/YouTube, and no data is sold, shared or used for advertising.

Google API Services

This app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy. Dark Atlas Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all data stored by the app.
